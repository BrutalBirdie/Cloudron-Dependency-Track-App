Dependency-Track is an intelligent Component Analysis platform that allows organizations to identify and reduce risk in the software supply chain. It ingests CycloneDX SBOMs and tracks every component across all projects and versions.

### Features

* Finds known vulnerabilities from NVD, GitHub Advisories, OSV and others
* Flags outdated components by checking npm, PyPI, Packagist, Maven, Go and more
* Policy engine for security, license and operational rules
* License risk tracking
* REST API for CI/CD integration
