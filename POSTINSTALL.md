Log in with username `admin` and password `admin`. You are asked to set a new password on first login.

<sso>
The local login form is under **More options** on the login page.

Cloudron users are created on first login without any permissions. To grant access, create a team under **Administration → Access Management → Teams** and map it to a Cloudron group under **OpenID Connect Groups**. Group membership is synchronized on every login.
</sso>

The first vulnerability database download takes several minutes after install.
